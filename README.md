# TEXT SPIDER
 
A Chrome extension that searches the current web page to the matching word closest to where youre reading.

 
## Features

any web pages for a word 
shows an error message if the search can't be found

## Installation
 
1. Download repository
2. Open chrome extentions
3. Turn on **Developer mode** in the top right
4. Click **Load unpacked** and select the folder
5. Pin it so you can use it when nessecary
